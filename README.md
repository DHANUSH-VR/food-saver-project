# Food Saver – Food Donation Web Application

## Overview
Food Saver is a responsive web application designed to connect food donors with recipients and reduce food wastage.

## Features
* User Authentication
* Food Request Management
* Responsive Design
* Donor & Recipient Dashboard
* Data Insights

## Technologies Used
* HTML
* CSS
* JavaScript
* Git & GitHub

## Future Improvements
* Database Integration
* Real-time Notifications
* AI-based Food Distribution
